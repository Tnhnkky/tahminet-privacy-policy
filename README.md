# Tahmin'et — Gizlilik Politikası

Son güncelleme: 28 Mayıs 2025

## Toplanan Veriler

Tahmin'et uygulaması aşağıdaki verileri toplar:

- **Hesap bilgileri:** E-posta adresi, kullanıcı adı (Google veya Apple ile giriş)
- **Oyun verileri:** Oyun istatistikleri, XP, sıralama bilgileri
- **Cihaz bilgileri:** Reklam gösterimi için cihaz tanımlayıcıları (AdMob)

## Verilerin Kullanımı

Toplanan veriler yalnızca şu amaçlarla kullanılır:

- Oyun deneyimini kişiselleştirmek
- Sıralama ve arkadaşlık özelliklerini sağlamak
- Reklam göstermek (Google AdMob)

## Üçüncü Taraf Hizmetler

- **Supabase:** Veri depolama ve kimlik doğrulama
- **Google AdMob:** Reklam gösterimi
- **RevenueCat:** Uygulama içi satın alma yönetimi
